Swiggy Sales Dashboard

Project Overview

This Power BI project analyzes Swiggy sales data and transforms raw business data into meaningful insights through interactive visualizations and dashboards. The dashboard helps stakeholders understand sales performance, customer behavior, revenue trends, and business growth opportunities.

Project Objectives

Analyze overall sales performance and revenue trends.
Identify top-performing food categories and products.
Understand customer ordering behavior and purchasing patterns.
Track key business KPIs for better decision-making.
Provide interactive visualizations for data-driven insights.

Dataset Processing

Collected and imported sales data into Power BI.
Performed data cleaning and preprocessing.
Handled missing and duplicate records.
Created calculated columns and measures using DAX.
Established relationships between multiple datasets.
